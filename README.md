# 🎯 Number Guessing Game – Multi-Player

A fun and interactive number guessing game made with **JavaScript**, **Bootstrap**, and **GSAP** animations. In this game, a random number is generated, and three players try to guess it. If any player matches the number, they win — otherwise, they lose!

## 🚀 Features

- 🔢 Random number generation using JavaScript
- 👤 Three-player input system
- 🧠 Math-based logic for number comparison
- ✨ Smooth animations using [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
- 🎨 Responsive and styled using [Bootstrap 5](https://getbootstrap.com/)



## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **Bootstrap 5** – for responsive layout and design
- **JavaScript** – game logic and interactivity
- **GSAP** – animations and transitions
